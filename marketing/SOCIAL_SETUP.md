(platforms require a real person, phone/email verification and security checks).

## Step 0 — Before you start (5 min)

1. **Coatwright email:** `coatwrightapp@gmail.com`. Use it for every account below, so the business stays separate from your personal accounts.
2. **Use a password manager** (Google Password Manager, iCloud Keychain or Bitwarden) and a different password per account.
3. **Turn on two-factor login** on every account after you create it. Losing a brand account is painful.
4. **Username to try everywhere, in this order:**
   1. `coatwright`
   2. `coatwrightapp`
   3. `getcoatwright`
   4. `coatwright.app` (Instagram allows dots) or `coatwright_app`

   Use the **same** username on every platform if you can. If #1 is taken anywhere, consider using #2 everywhere.

## Instagram (do this first: it also sets up Facebook)

1. Download Instagram → **Create new account** → use the Coatwright email → username from Step 0.
2. Name: **Coatwright · Paint Quotes**: the name field is searchable, so "Paint Quotes" helps painters find you.
3. Profile photo: `profile-picture.png`.
4. Settings → **Account type and tools → Switch to professional account → Business** → category **App page** (or the closest software/app option).
5. Bio (150 characters max), copy and paste:

```
🎨 Free quoting & business app for painters
⚡ Itemized quotes in minutes
🧾 Invoices · 📊 your real profit
👇 Start free, no signup
```

6. Add link → the link above.
7. First post: `first-post.png` with the caption in the "First posts" section below.

## Facebook Page

1. On Facebook (your personal account is needed to own a Page, but the Page is separate and your name isn't shown) → **Pages → Create new Page**.
2. Page name: **Coatwright** · Category: **App Page** (or Software).
3. Bio / intro (101 characters max):

```
Free app for painters: itemized quotes in minutes, invoices and your real profit. Start free 👇
```

4. Profile picture: `profile-picture.png` · Cover photo: `facebook-cover.png`.
5. Website: the link above. Action button: **Learn more** → the link above.
6. Username: Page settings → **Username** → `coatwright`.
7. **Connect Instagram:** Page settings → Linked accounts → Instagram. Now you can post to both at once.

2. Handle: `@coatwright`.
