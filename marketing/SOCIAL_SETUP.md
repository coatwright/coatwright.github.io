## 1. Instagram

**Create the account**

| Screen asks | Your answer |
|---|---|
| (Already logged in with your personal Instagram?) | Go to your profile → tap your username at the top → **Add Instagram account** → **Create new account** |
| "What's your mobile number?" | Tap **Sign up with email** |
| "What's your email?" | `coatwrightapp@gmail.com` |
| "Enter the confirmation code" | Open Gmail, copy the code from Instagram |
| "Create a password" | A strong new password → save it in your password manager |
| "Save your login info?" | **Save** |
| "What's your birthday?" | Your real birthday |
| "What's your name?" | `Coatwright · Paint Quotes` (the name is searchable, so "Paint Quotes" helps painters find you) |
| "Create a username" | `coatwright` (or the next one in the list) |
| "Agree to Instagram's terms" | **I agree** |
| "Add profile picture" | Choose the saved **profile picture** |
| "Find friends / allow contacts" | **Skip** (don't sync your personal contacts to the business account) |
| "Turn on notifications" | Your choice |

**Make it a business account**

1. Profile → **☰ menu** (top right) → **Settings and activity** → **Account type and tools** → **Switch to professional account**.
2. "What best describes you?" → search **App page** (or the closest software/app category) → **Done**. You can switch "Display on profile" on.
3. "Are you a creator or business?" → **Business** → **Next**.
4. "Review your contact info" → Email `coatwrightapp@gmail.com`; leave phone empty → **Next**.
5. "Connect to Facebook" → **Skip** (you'll connect from the Facebook Page in step 2).

**Finish the profile:** Profile → **Edit profile**

| Field | Enter |
|---|---|
| Bio | Copy the bio below |
| Links → Add external link | URL `https://coatwright.github.io/` · Title `Start free` |

```
🎨 Free quoting & business app for painters
⚡ Itemized quotes in minutes
🧾 Invoices · 📊 your real profit
👇 Start free, no signup
```

**First post:** + → Post → choose **first post** image → paste the "Post 1" caption from the bottom of this guide → Share.

## 2. Facebook Page

A Facebook Page is created from your personal Facebook account, but it's a separate business page.
Your personal name is not shown on it.

| Screen asks | Your answer |
|---|---|
| Start | In the Facebook app: **☰ Menu → Pages → + Create** (computer: facebook.com/pages/create) → **Get started** |
| "Page name" | `Coatwright` |
| "Category" | Type **App Page** and select it (or "Software") |
| "Bio" (optional, 101 characters) | `Free app for painters: itemized quotes in minutes, invoices and your real profit. Start free 👇` |
| **Create Page** | Tap it |
| "Contact info: Website" | `https://coatwright.github.io/` |
| "Contact info: Email" | `coatwrightapp@gmail.com` |
| "Phone / Address / Hours" | Leave empty, or choose **No hours available** |
| "Add profile picture" | **profile picture** |
| "Add cover photo" | **Facebook cover** |
| "Connect WhatsApp" | **Skip** |
| "Grow your Page / Invite friends" | Optional: inviting friends gets your first likes |
| "Stay informed about your Page" | Your choice → **Done** |

**Then, on the Page:**

1. **Username:** Page → **⋯** → **Settings** → **Username** (or Page info) → `coatwright`. Your Page link becomes facebook.com/coatwright.
2. **Button:** on the Page, tap **+ Add action button** → **Learn more** (or **Sign up**) → Website → `https://coatwright.github.io/` → Save.
3. **Connect Instagram:** Page → **Settings → Linked accounts** (or **Professional dashboard → Linked accounts**) → **Instagram → Connect account** → log in with the Coatwright Instagram. Now you can post to both at once.
4. **First post:** same image and caption as Instagram (or tick "Share to Facebook" when posting on Instagram).

## After each account: protect it (1 min each)

Turn on **two-factor authentication** (2FA). Use an authenticator app or text messages to your personal phone:

- **Instagram:** ☰ → Accounts Center → Password and security → Two-factor authentication
- **Facebook:** Settings → Accounts Center → Password and security → Two-factor authentication
- **TikTok:** Settings and privacy → Security → 2-step verification
- **YouTube:** protected by the Google account: turn on 2-Step Verification for coatwrightapp@gmail.com
- **X:** Settings → Security and account access → Security → Two-factor authentication
